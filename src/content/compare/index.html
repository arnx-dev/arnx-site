Where arnx fits next to other review tools.

Most of these tools review the pull request. arnx tests the change before it.

arnx is an open-source CLI that writes and runs tests for a finished change on your own machine. Pull request reviewers comment on the diff for a whole team. These are different jobs, and each page below says when the other tool is the better choice and how the two fit together.

Every statement about another product links to that product's own documentation and carries the date we read it. Where we could not find something in their documentation, we say that, and do not say the product lacks it.
